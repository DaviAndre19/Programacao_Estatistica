# Programação Estatística
Este espaço é destinado à divulgação de códigos realizados na disciplina de Programação Estatística da UFSCar no período de 2025/2.
Todos os laboratórios feitos durante a disciplina foram feitos de maneira amadora, uma vez que foi o meu primeiro contato com os tópicos abordados.
Os códigos foram feitos para aprendizado da matéria de maneira rápida e usual para mim na época, então é nítido que alguns códigos podem ser feitos de outras maneiras e de formas mais eficazes e intuitivas.
